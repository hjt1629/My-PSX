# My PSX

PhotoScape X에서 영감을 받은 macOS용 사진 뷰어 & 간단 편집기입니다.
Swift + SwiftUI로 만든 네이티브 앱이라 빠르고 가볍습니다.

## 화면 구성 (PhotoScape X 스타일)

어두운 테마에, 창 위쪽의 글자 탭 줄(`사진 뷰어 | 사진 편집 | 오려내기`)로 화면을 바꿉니다.

| 탭 | 구성 |
|---|---|
| **사진 뷰어** (⌘1) | 왼쪽 폴더 트리(`폴더 \| 즐겨찾기`, 지금 폴더까지 자동으로 펼침) · 위쪽 뒤로·앞으로·위로, 경로, 정렬 · 가운데 썸네일 또는 크게 보기 · 아래 상태 막대 |
| **사진 편집** (⌘2) | 왼쪽 파일 탐색(위: 폴더 트리, 아래: 현재 폴더 썸네일, 맨 아래: ★ ↻ ← → ↑) · 가운데 위 `✕ < > 파일 이름` · 가운데 사진 · 오른쪽 `편집 \| 조정 \| AI` 패널 · 아래 막대(원본 비교, 되돌리기, 다시하기, 원래대로, 저장) |
| **오려내기** (⌘3) | 사진 편집과 같은 왼쪽 파일 탐색 · 오른쪽: 자동 배경 제거, 배경색 채우기, 투명 PNG 저장 |

편집 중인 사진은 탭을 오가거나 왼쪽 트리에서 다른 폴더로 가도 그대로 유지됩니다.

## 기능

**뷰어**
- 폴더 단위로 사진 보기, 폴더 트리 / 즐겨찾기 / 마지막으로 연 폴더 기억
- JPEG, PNG, HEIC, TIFF, GIF, WebP, RAW(CR2, NEF, ARW, DNG 등) 등 macOS가 읽을 수 있는 모든 형식

**사진 편집**
- 자르기: 드래그로 영역 선택, 비율 고정 (자유, 원본, 1:1, 4:3, 3:2, 16:9 …)
- 크기 조절: 픽셀 입력, 비율 유지, 25% / 50% / 75% / 200%
- 회전: 왼쪽 / 오른쪽 90°, 좌우 / 상하 반전
- 원본 비교(누르고 있는 동안), 실행 취소 / 다시 실행(최대 30단계), 원래대로
- 저장 시 촬영 날짜, 카메라, GPS 등 원본 정보 유지

**확대 / 축소**
- 트랙패드 핀치로 확대·축소(손가락 위치 기준), 확대된 상태에서 두 손가락 스크롤로 이동
- 마우스 휠 또는 ⌘+스크롤로 확대·축소, 오른쪽 아래 배율 표시를 누르면 화면에 맞춤

**자르기**
- 선택 영역 저장(⌘A): 사진은 그대로 두고 선택한 부분만 새 파일로 (기본 위치 = 사진이 있는 폴더)
- 클립보드에 복사(⌘B)

**조정**
- 라이트룸 '기본' 패널처럼 접고 펼 수 있는 묶음 (움직이는 즉시 미리보기, '적용'으로 원본 크기에 반영)
  - 흰색 균형: 색온도, 색조
  - 톤: 노출, 밝기, 대비, 밝은 영역, 어두운 영역, 흰색 계열, 검정 계열
  - 외관: 부분 대비, 생동감, 채도
  - 세부 · 효과: 선명하게, 비네팅
- 슬라이더 이름 더블클릭 = 0으로, 묶음마다 '초기화'

**화면**
- 좌우 패널 사이 경계선을 끌어 너비 조절 (더블클릭하면 원래 너비, 다음 실행 때도 유지)

**AI (GPT)**
- 원하는 수정을 글로 쓰면 GPT가 사진을 고쳐 줌 (예: "배경을 흰색으로 바꿔줘")
- 설정(⌘,)에서 연결 방식 선택
  - **ChatGPT 구독 (Codex CLI)** — 실험 기능. API 키·추가 요금 없이 구독의 Codex 사용량으로 동작.
    처음 한 번 터미널에서 `brew install codex` (또는 `npm install -g @openai/codex`) → `codex login`.
    OpenAI가 공식 지원하는 연동 방식이 아니라 Codex 업데이트에 따라 안 될 수 있고, 이미지를 새로 그리므로 수십 초 이상 걸립니다.
  - **OpenAI API 키** — 사용량만큼 별도 과금, 키는 macOS 키체인에 저장. 모델 선택 가능(기본 `gpt-image-1.5`).
  - **Higgsfield 구독 (CLI)** — `brew install higgsfield-ai/tap/higgsfield` 후 `higgsfield auth login`. API 키 없이 구독 크레딧 사용. 배경 제거는 전용 모델 `image_background_remover`, 글로 하는 수정은 `gpt_image_2_5`.
- 수정할 사진은 OpenAI로 전송됩니다. 결과는 '되돌리기'로 취소할 수 있습니다.

**오려내기**
- 기본은 **흰색 배경**, **"투명 배경으로" 체크박스**를 켜면 투명 PNG
- **빠른 배경 제거** (⇧⌘B) — 설정에서 고른 AI로 처리. Higgsfield 구독이면 배경 제거 전용 모델(1장 ≈ 1크레딧, 상품은 원본 그대로), GPT(Codex 또는 API)면 상품만 남기고 배경·아이콘·글자를 흰색(또는 투명)으로 정리. 맥 AI는 쓰지 않음. Codex는 생각 단계 없이 이미지 도구를 바로 한 번만 부르는 최소 설정으로 실행 (걸린 시간은 아래 막대에 표시)
- 맥 AI로 제거 (⌥⌘B, 무료·오프라인·1초) — "가장 큰 물체만 남기기"로 작은 아이콘·글자·소품 제거. 테두리가 거칠 수 있음
- 투명한 배경을 원하는 색으로 채우기

## 맥북에 설치 / 업데이트

터미널에서 처음 한 번만:

```bash
xcode-select --install   # Command Line Tools (이미 있으면 건너뜀)
git clone -b claude/photo-viewer-editor https://github.com/hjt1629/My-PSX.git ~/My-PSX
~/My-PSX/scripts/install.sh
```

최신 코드를 받아 앱을 만들고 `/Applications/MyPSX.app`에 설치한 뒤 실행합니다. 맥에서 직접 만든 앱이라 보안 경고가 뜨지 않습니다.
이후에는 앱 메뉴 **My PSX → 업데이트…** 를 누르면 같은 일을 하고 앱이 다시 켜집니다. (기록: `~/Library/Logs/MyPSX-update.log`)

## 요구 사항

- macOS 14 (Sonoma) 이상
- Xcode 15 이상 (또는 `xcode-select --install` 로 설치한 Command Line Tools)

## 실행 방법

### 1) 바로 실행 (개발용)
```bash
swift run
```

### 2) Xcode로 열기
`Package.swift` 를 더블클릭해서 Xcode로 연 뒤 ▶︎ 버튼을 누릅니다.

### 3) 앱(.app)으로 만들기
```bash
./scripts/build-app.sh
open build/MyPSX.app
```
만들어진 `build/MyPSX.app` 을 `응용 프로그램` 폴더로 옮기면 일반 앱처럼 쓸 수 있습니다.

## 테스트

```bash
swift test
```

배경 제거 테스트는 실제 Mac에서만 동작하므로(가상 머신에는 Neural Engine이 없음) 사진 경로를 지정했을 때만 실행됩니다.

```bash
PSX_SUBJECT_PHOTO="/Library/User Pictures/Animals/Zebra.heic" swift test
```

## 구조

```
Sources/
  PSXCore/          이미지 불러오기·편집·저장 (UI 없음, 테스트 대상)
    ImageLoader     파일 → 이미지, 썸네일
    ImageOps        회전, 반전, 자르기, 크기 조절, 배경 제거
    ImageExporter   이미지 → 파일 (메타데이터 유지, 안전한 덮어쓰기)
  MyPSX/            SwiftUI 앱
    FolderBrowser   폴더 탐색 / 탭 / 열린 사진 상태
    PhotoEditor     편집 상태 / 실행 취소 기록
    Views/          화면 (ViewerView, EditorWorkspace, EditPanels, Theme …)
Tests/PSXCoreTests  편집 기능 테스트 (`swift test`)
```
