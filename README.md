# My PSX

PhotoScape X에서 영감을 받은 macOS용 사진 뷰어 & 간단 편집기입니다.
Swift + SwiftUI로 만든 네이티브 앱이라 빠르고 가볍습니다.

## 화면 구성 (PhotoScape X 스타일)

어두운 테마에, 창 위쪽의 글자 탭 줄(`사진 뷰어 | 사진 편집 | 오려내기`)로 화면을 바꿉니다.

| 탭 | 구성 |
|---|---|
| **사진 뷰어** (⌘1) | 왼쪽 폴더 트리(`폴더 \| 즐겨찾기`, 지금 폴더까지 자동으로 펼침) · 위쪽 뒤로·앞으로·위로, 경로, 정렬 · 가운데 썸네일 또는 크게 보기 · 아래 상태 막대 |
| **사진 편집** (⌘2) | 왼쪽 파일 탐색(위: 폴더 트리, 아래: 현재 폴더 썸네일, 맨 아래: ★ ↻ ← → ↑) · 가운데 위 `✕ < > 파일 이름` · 가운데 사진 · 오른쪽 `편집 \| 조정 \| AI` 패널 · 아래 막대(원본 비교, 되돌리기, 다시하기, 원래대로, 저장) |
| **오려내기** (⌘3) | 사진 편집과 같은 왼쪽 파일 탐색 · 오른쪽: 자동 배경 제거, 배경색 채우기, 투명 PNG 저장 |

편집 중인 사진은 탭을 오가거나 왼쪽 트리에서 다른 폴더로 가도 그대로 유지됩니다.

## 기능

**뷰어**
- 폴더 단위로 사진 보기, 폴더 트리 / 즐겨찾기 / 마지막으로 연 폴더 기억
- JPEG, PNG, HEIC, TIFF, GIF, WebP, RAW(CR2, NEF, ARW, DNG 등) 등 macOS가 읽을 수 있는 모든 형식

**사진 편집**
- 자르기: 드래그로 영역 선택, 비율 고정 (자유, 원본, 1:1, 4:3, 3:2, 16:9 …)
- 크기 조절: 픽셀 입력, 비율 유지, 25% / 50% / 75% / 200%
- 회전: 왼쪽 / 오른쪽 90°, 좌우 / 상하 반전
- 원본 비교(누르고 있는 동안), 실행 취소 / 다시 실행(최대 30단계), 원래대로
- 저장 시 촬영 날짜, 카메라, GPS 등 원본 정보 유지

**조정**
- 밝기 / 대비 / 채도 슬라이더 (움직이는 즉시 미리보기, '적용'으로 원본 크기에 반영)

**AI (GPT)**
- 원하는 수정을 글로 쓰면 OpenAI 이미지 모델이 사진을 고쳐 줌 (예: "배경을 흰색으로 바꿔줘")
- 오려내기 탭의 "GPT로 배경 제거" (투명 PNG)
- 설정(⌘,)에서 OpenAI API 키 입력 — macOS 키체인에 저장, 모델 선택, 연결 확인
- ⚠️ ChatGPT 구독(Plus/Pro)과는 별개로 **OpenAI API 사용량만큼 요금**이 나가며, 수정할 사진은 OpenAI로 전송됩니다.
  ChatGPT 구독을 다른 앱에서 쓰는 "Sign in with ChatGPT"는 현재 OpenAI가 승인한 파트너 앱에만 열려 있습니다.
- 배경 제거에는 투명 배경을 지원하는 `gpt-image-1.5`(기본값)를 쓰세요. `gpt-image-2`는 투명 배경을 지원하지 않습니다.

**오려내기**
- macOS 내장 Vision 프레임워크로 배경 제거 (인터넷 연결이나 추가 설치 불필요)
- 투명한 배경을 원하는 색으로 채우기

## 요구 사항

- macOS 14 (Sonoma) 이상
- Xcode 15 이상 (또는 `xcode-select --install` 로 설치한 Command Line Tools)

## 실행 방법

### 1) 바로 실행 (개발용)
```bash
swift run
```

### 2) Xcode로 열기
`Package.swift` 를 더블클릭해서 Xcode로 연 뒤 ▶︎ 버튼을 누릅니다.

### 3) 앱(.app)으로 만들기
```bash
./scripts/build-app.sh
open build/MyPSX.app
```
만들어진 `build/MyPSX.app` 을 `응용 프로그램` 폴더로 옮기면 일반 앱처럼 쓸 수 있습니다.

## 테스트

```bash
swift test
```

배경 제거 테스트는 실제 Mac에서만 동작하므로(가상 머신에는 Neural Engine이 없음) 사진 경로를 지정했을 때만 실행됩니다.

```bash
PSX_SUBJECT_PHOTO="/Library/User Pictures/Animals/Zebra.heic" swift test
```

## 단축키

| 동작 | 단축키 |
|---|---|
| 사진 뷰어 / 사진 편집 / 오려내기 탭 | ⌘1 / ⌘2 / ⌘3 |
| 폴더 열기 | ⌘O |
| 뒤로 / 앞으로 / 상위 폴더 (뷰어) | ⌘[ / ⌘] / ⌘↑ |
| 새로고침 | ⌘R |
| 사진 선택 이동 (뷰어) | ← → ↑ ↓ |
| 크게 보기 (뷰어) | Return, Space 또는 더블클릭 (닫기: Esc / Space) |
| 크게 보기에서 사진 편집 | Return |
| 이전 / 다음 사진 | ← / → |
| 뷰어로 돌아가기, 도구 닫기 | Esc |
| 왼쪽 / 오른쪽 회전 (사진 편집) | ⌘[ / ⌘] |
| 자르기 | ⌘K (적용: Return) |
| 크기 조절 | ⌥⌘I (적용: Return) |
| 배경 제거 | ⇧⌘B |
| 되돌리기 / 다시하기 | ⌘Z / ⇧⌘Z |
| 저장 / 다른 이름으로 저장 | ⌘S / ⇧⌘S |

## 구조

```
Sources/
  PSXCore/          이미지 불러오기·편집·저장 (UI 없음, 테스트 대상)
    ImageLoader     파일 → 이미지, 썸네일
    ImageOps        회전, 반전, 자르기, 크기 조절, 배경 제거
    ImageExporter   이미지 → 파일 (메타데이터 유지, 안전한 덮어쓰기)
  MyPSX/            SwiftUI 앱
    FolderBrowser   폴더 탐색 / 탭 / 열린 사진 상태
    PhotoEditor     편집 상태 / 실행 취소 기록
    Views/          화면 (ViewerView, EditorWorkspace, EditPanels, Theme …)
Tests/PSXCoreTests  편집 기능 테스트 (`swift test`)
```
